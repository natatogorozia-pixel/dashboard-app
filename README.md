# B2B Logistics Dashboard (`dashboard-app`)

## 📋 ბიზნეს-აღწერა
ეს პროექტი წარმოადგენს თანამედროვე **B2B ლოჯისტიკურ პლატფორმას (ლოჯისტიკა)**, რომელიც უზრუნველყოფს საწყობების, სატრანსპორტო ნაკადებისა და ფინანსური მონაცემების ინტერაქციულ მართვას (CRUD). სისტემა აერთიანებს ფორმების მკაცრ ტიპიზირებულ ვალიდაციას, შეცდომების უსაფრთხო მართვას (`Error Boundary`) და ოფლაინ/ქეშირებულ რეჟიმში მუშაობას.

## 🚀 ძირითადი ფუნქციონალი და ტექნოლოგიები
- **React & Vite:** სწრაფი აწყობა და კომპონენტური არქიტექტურა.
- **TypeScript:** სტატიკური ტიპიზაცია და კოდის უსაფრთხოება.
- **React Router:** დინამიური ნავიგაცია და მარშრუტების მართვა.
- **Axios:** სერვერთან ასინქრონული კომუნიკაცია.
- **Styled Components / Tailwind / Custom CSS:** ადაპტირებადი და რესფონსივი დიზაინი (Responsive Design).
- **Zod & React Hook Form:** ფორმების ეფექტური მართვა და მკაცრი ვალიდაცია (Fail-Fast პრინციპით).
- **React Error Boundary:** აპლიკაციის დაცვა თეთრი ეკრანისა და უმართავი Runtime შეცდომებისგან (Retry მექანიზმით).
- **Portal Modals (`ReactDOM.createPortal`):** მოდალური ფანჯრები სწორი DOM სტრუქტურით.
- **Performance Tools:** `useMemo`, `useCallback`, `React.memo` და მედიაფაილების ოპტიმიზაცია (`WebP`).
