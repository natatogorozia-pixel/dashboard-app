# B2B Logistics Dashboard (`dashboard-app`)

რეაქტზე (React/Vite) აწყობილი თანამედროვე ლოჯისტიკური დეშბორდი, რომელიც უზრუნველყოფს საწყობების, ტრანსპორტისა და ფინანსური მონაცემების ინტერაქციულ მართვას (CRUD), ფორმების ვალიდაციას, შეცდომების მართვას და ოფლაინ რეჟიმში მუშაობას.

## 🚀 ძირითადი ფუნქციონალი და ტექნოლოგიები

- **React & Vite:** სწრაფი აწყობა და კომპონენტური არქიტექტურა.
- **Zod Validation:** ტიპიზირებული და მკაცრი ფორმის ვალიდაცია (Fail-Fast პრინციპით).
- **React Error Boundary:** აპლიკაციის დაცვა თეთრი ეკრანისა და უმართავი Runtime შეცდომებისგან (Retry მექანიზმით).
- **DevTools Debugging:** კონსოლის გაუმჯობესებული მეთოდები (`console.time`, `console.table`).
- **Portal Modals (`ReactDOM.createPortal`):** მოდალური ფანჯრები სწორი DOM სტრუქტურით.
- **Offline / Fallback Mode:** ავტომატური გადართვა ქეშირებულ დემო მონაცემებზე სერვერთან კავშირის გაწყვეტისას.
- **Double-Click Prevention:** ასინქრონული შენახვისას ღილაკების დეაქტივაცია (Overbooking-ის პრევენცია).
- **Responsive Design:** ადაპტირებადი მობილური ჰამბურგერ მენიუ.
