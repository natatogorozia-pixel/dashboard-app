## 🎨 ეტაპი 1: UI/UX ანალიზი და დიზაინ-აუდიტი

### 1. Design Tokens დოკუმენტაცია
პროექტის სტილების სისტემა დაფუძნებულია ცენტრალიზებულ CSS ცვლადებზე (`:root`), რაც უზრუნველყოფს დიზაინ-სისტემის ერთგვაროვნებასა და მოქნილობას.
* **ფერის პალიტრა (Hex Codes):**
  * Primary (მთავარი ფერი): `#0284c7` (Sky Blue)
  * Background (ფონი): `#f8fafc` (Light Slate)
  * Text (ტექსტი): `#0f172a` (Dark Slate)
  * Danger / Pulse (კრიტიკული/ყურადღების): `#ef4444` (Red)
* **Spacing & Typography:** გამოყენებულია სტანდარტული ინტერვალები (`8px` ბადეზე დაფუძნებული) და ტიპოგრაფიული მასშტაბი (ძირითადი ფონტი: `16px`).

## ⚡ ეტაპი 4: ინტერაქციის ანალიზი და მიკრო-ინტერაქციები (დავალება №11)

### 1. არჩეული მოდული: B2B ტვირთების მართვა და ლაივ-ძიება (Logistics Fleet/Shipment Hub)

### 2. მიკრო-ინტერაქციების 4 ფაზა (Trigger, Rules, Feedback, Loops/Modes)

* **1. მიკრო-ინტერაქცია: ტვირთის ბარათზე Hover ეფექტი (Interactive StatCard)**
  * **Trigger (ტრიგერი):** მომხმარებლის მიერ კურსორის მიტანა (Hover) ან კლავიატურის `Tab` ღილაკით ფოკუსირება.
  * **Rules (წესები):** ელემენტმა უნდა გააკეთოს გლუვი წანაცვლება Y ღერძზე (`translateY(-4px)`) და გაეზარდოს ჩრდილი (`box-shadow`), GPU აქსელერაციით.
  * **Feedback (უკუკავშირი):** ბარათი ოდნავ მაღლა იწევს და ფონი იღებს უფრო მკვეთრ ჩრდილს.
  * **Loops / Modes:** დროებითი მდგომარეობაა (Hover/Focus state) — კურსორის გაწევისას ბარათი უბრუნდება საწყის პოზიციას.

* **2. მიკრო-ინტერაქცია: კრიტიკული სტატუსის პულსაცია (Pulse Indicator)**
  * **Trigger (ტრიგერი):** სისტემის მიერ ტვირთის დაყოვნების ან კრიტიკული მარაგის იდენტიფიცირება.
  * **Rules (წესები):** `@keyframes` ანიმაცია, რომელიც მუდმივად ცვლის წერტილის მასშტაბს (`transform: scale()`) და გამჭვირვალობას (`opacity`).
  * **Feedback (უკუკავშირი):** წითელი პულსირებადი წერტილი ტვირთის სტატუსის გვერდით.
  * **Loops / Modes:** უწყვეტი ციკლი (Infinite Loop) — პულსაცია გრძელდება მანამ, სანამ სტატუსი არ შეიცვლება.

* **3. მიკრო-ინტერაქცია: ლაივ-ძიება დებოუნსინგით (Debounced Search Input)**
  * **Trigger (ტრიგერი):** მომხმარებლის მიერ საძიებო ველში სიმბოლოების აკრეფა (`input` event).
  * **Rules (წესები):** მოთხოვნის გაგზავნა/ფილტრაცია ხდება აკრეფის შეწყვეტიდან 400ms-ის შემდეგ (`Debounce` ტექნიკა).
  * **Feedback (უკუკავშირი):** ტვირთების სია მომენტალურად განახლდება მხოლოდ აკრეფის დასრულების შემდეგ.
  * **Loops / Modes:** მდგომარეობის ცვლილება (Mode Change) — სია იფილტრება შეყვანილი ტექსტის მიხედვით.
