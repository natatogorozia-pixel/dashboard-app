# B2B Logistics Dashboard (`dashboard-app`)

## 📋 1. პროექტის არსი და ბიზნეს-კონცეფცია
ეს პროექტი წარმოადგენს თანამედროვე **B2B ლოჯისტიკურ პლატფორმას (ლოჯისტიკა)**, რომელიც უზრუნველყოფს საწყობების, სატრანსპორტო ნაკადებისა და ფინანსური მონაცემების ინტერაქციულ მართვას (CRUD). სისტემა აერთიანებს ფორმების მკაცრ ტიპიზირებულ ვალიდაციას, შეცდომების უსაფრთხო მართვას (`Error Boundary`), ოფლაინ/ქეშირებულ რეჟიმში მუშაობას და მონაცემთა ავტომატურ სინქრონიზაციას ბრაუზერის მეხსიერებასთან (`localStorage`).

### 👥 სამიზნე მომხმარებლები:
- **ლოჯისტიკის მენეჯერი:** შეკვეთების დინამიკისა და სატრანსპორტო სტატუსების მართვა.
- **საწყობის ადმინისტრატორი:** აქტიური ტრანსპორტისა და დაყოვნებული ტვირთების კონტროლი.
- **ფინანსური ანალიტიკოსი:** შემოსავლების დინამიკისა და პროცენტული მაჩვენებლების მონიტორინგი.

## 🚀 2. ძირითადი ფუნქციონალი და ტექნოლოგიური სტეკი
- **React & Vite:** სწრაფი აწყობა და კომპონენტური არქიტექტურა.
- **TypeScript:** სტატიკური ტიპიზაცია და კოდის უსაფრთხოება.
- **Zustand (`persist` middleware):** გლობალური სთეითის ცენტრალიზებული მართვა (`Single Source of Truth`) და `localStorage`-თან სინქრონიზაცია.
- **Zod & React Hook Form:** ფორმების ეფექტური მართვა და მკაცრი ვალიდაცია (Fail-Fast პრინციპით).
- **React Error Boundary:** აპლიკაციის დაცვა თეთრი ეკრანისა და უმართავი Runtime შეცდომებისგან (Retry მექანიზმით).
- **Portal Modals (`ReactDOM.createPortal`):** მოდალური ფანჯრები სწორი DOM სტრუქტურით.
- **Performance Tools:** `useMemo`, `useCallback`, `React.memo`, `useDebounce` და მედიაფაილების ოპტიმიზაცია (`WebP`).

---

## 🧠 3. ტექნიკური არქიტექტურა და მდგრადობა
- **State Management:** მონაცემები იმართება `useLogisticsStore`-ით. Zustand-ის `persist` მიდლვეარის მეშვეობით გვერდის გადატვირთვისას (`Refresh`) მონაცემები არ იკარგება.
- **Defensive Programming:** დანერგილია `ErrorBoundary` თეთრი ეკრანის თავიდან ასაცილებლად, `isSubmitting` მდგომარეობა ფორმების Double-Click-ის პრევენციისთვის და ქეშირებული დემო-მონაცემები ოფლაინ რეჟიმისთვის.
- **Responsive Design:** ინტერფეისი სრულად ადაპტირებულია დესკტოპ (1440px), პლანშეტ (768px) და მობილურ (375px) ეკრანებზე.
